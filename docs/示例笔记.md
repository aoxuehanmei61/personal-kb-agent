# 示例笔记（测试用，可删除）

## 这个知识库是做什么的
这是一个接入 DeepSeek 大模型的个人知识库 Agent。你把自己的 Markdown、TXT、PDF、Word
文档放进 docs 文件夹后，它会先在本地检索出和问题最相关的几段内容，再交给 DeepSeek
据此回答，避免模型凭空编造。

## 支持的文档格式
- Markdown（.md）和纯文本（.txt）：直接读取；
- PDF（.pdf）：提取文字层内容；
- Word（.docx）：读取段落文本；
- 图片里的文字（扫描件 PDF）当前不支持，需要先 OCR。

## 怎么用
1. 在 .env 里填好 DeepSeek API Key；
2. 把资料放进 docs 文件夹；
3. 运行 `python main.py`，输入问题即可；
4. 中途往 docs 里加了新文档，输入 `/reload` 重新加载。

## 检索原理
当前用本地 TF-IDF 关键词召回（中文用 jieba 分词），不依赖外部向量服务。
优点是轻量、好安装；后续如果想要更准的语义检索，可以把 retriever.py 里的召回
换成本地或云端的 embedding 向量。
